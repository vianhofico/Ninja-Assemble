# Naruto Complete Roster+

## Goal

The private mobile release targets a roster larger than the reference Ninja Assemble build while preserving the same collection/progression feel.

Release target:

- at least 180 distinct playable base characters;
- 300+ meaningful playable forms/variants after transformation census;
- all combat-relevant named Naruto + Naruto Shippuden characters represented in the census;
- major anime/movie characters can be enabled as expansion content after the core roster is complete.

This does not treat every unnamed/background person as a playable hero. A playable entry must have enough combat identity to support a skill kit and presentation package.

## Required roster groups

- Konoha generations and clans;
- Uchiha, Senju and Uzumaki historical characters;
- all major Suna, Kiri, Kumo, Iwa, Ame and Oto combatants;
- complete Akatsuki combat roster;
- all canonical Jinchuriki/Tailed Beast hosts relevant to Naruto/Shippuden;
- Kage and former Kage;
- Seven Ninja Swordsmen and other notable village elites;
- Sound Four and Orochimaru network;
- Fourth Shinobi World War/Edo forms where gameplay differs materially;
- Six Paths/ancient characters;
- summons only when they work as standalone combat units;
- selected anime/movie expansion characters after core completion.

## Variant rule

A form becomes a separate playable variant when it changes one or more of:

1. core skill kit;
2. combat resource/transform state;
3. silhouette/model or signature VFX;
4. role/archetype;
5. progression rarity/tier enough to justify separate collection value.

Examples include Sage Mode, KCM, Six Paths, Susanoo, Mangekyo/Rinnegan, Curse Mark, Edo Tensei and Jinchuriki cloak forms.

## Character Definition of Done

Every release-candidate variant requires:

- catalog metadata;
- EN + VI name/title/skill text;
- stats and growth table;
- active/basic/passive/ultimate definitions as applicable;
- progression/evolution mapping;
- high-resolution portrait;
- chibi battle body at the approved 2–2.5-head visual standard;
- idle/move/basic/hit/death/victory animations;
- skill/ultimate animation timeline;
- VFX and SFX hooks;
- UI icon/card frame;
- battle tests;
- visual-regression reference;
- parity/census status.

No placeholder presentation asset may remain in the private mobile release candidate.
