# M76 Physical Android Evidence

Only evidence captured from real Android hardware belongs here or in `mobile-device-evidence.csv`. Emulator results may help development but cannot certify release.

A release row/report must identify the exact tested commit, Unity version and APK/AAB artifact, include device model/Android version/build fingerprint, classify the device as LOW/MID/HIGH, use benchmark profile `m76-device-profiles-v1`, pass smoke and class-specific performance thresholds, and retain a capture reference.

M76 requires at least two passing physical Android models across at least two device classes. No sample PASS evidence is committed by this milestone.
